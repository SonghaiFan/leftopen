# Security Policy

## Supported Versions

LeftOpen actively maintains and provides security updates for the latest released version.

| Version | Supported          |
| ------- | ------------------ |
| >= 0.4.0 | :white_check_mark: |
| < 0.4.0  | :x:                |

## Reporting a Vulnerability

If you discover a potential security issue or vulnerability in LeftOpen, please report it responsibly:

1. **Do not** report security vulnerabilities through public GitHub issues.
2. Please submit reports privately through [GitHub Private Vulnerability Reporting](https://github.com/SonghaiFan/leftopen/security/advisories/new) or directly contact the maintainer via email.
3. Please provide a clear description of the vulnerability, steps to reproduce, and the potential impact.

We take security seriously and will acknowledge receipt of your vulnerability report within 48 hours and work with you on a resolution before any public disclosure.
